FAQ

常见问题

谁可以铸造？
持有币安 Agent ID 的钱包。铸造时合约会当场验证你的 ID，没有 ID 的钱包调用会被直接拒绝。
基础价格是多少？
0.002 BNB / 份，每份 5,000 万枚牛币。前 10,000 份都是这个价，之后进入分级曲线逐档递增。
何时开放交易？
累计铸造满 10,000 份时，合约自动用 70% 的资金建立 PancakeSwap 流动性池并开放交易，没有人工开关。铸造的牛币在开盘前就进入你的钱包，但开盘前不可转账、不可卖。
每个钱包能打多少？
基础额度 10 份 / 钱包（按 Agent ID 计）。这是刻意的公平设计：不让大户包场。
财库的钱归谁管？
每笔铸造的 30% 进入 Safe 2-of-3 多签财库（地址见下方），动账需要至少 2 名成员签名，链上全程可查。
这是投资建议吗？
不是。牛币是社区 meme 代币，波动极大、可能归零。本页只陈述合约机制，不构成任何投资建议。
